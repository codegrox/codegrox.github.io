CS180 Project 1 - Images of the Russian Empire
Hovhannes Antablyan

Files
-----
align.py   alignment code (single-scale, pyramid, NCC/L2, gradient feature)
main.py    runs the code on the provided and extra images

Setup
-----
Python 3.9+

pip install numpy scikit-image pillow

Data
----
Provided plates are in:
  data/course/

My additional Prokudin-Gorskii plates are in:
  data/extra/

Run
---
From the cs180_proj1 folder:

python code/main.py --data data/course --extra data/extra --out out

The script runs:
- single-scale NCC and L2 on the small JPG images
- pyramid NCC on all provided images
- pyramid NCC on the extra images
- pyramid L2 for comparison
- gradient NCC for comparison, mainly to improve Emir

It prints the G and R offsets and writes results.csv and results.md.
Full-size results go under out/. Smaller webpage copies generated by the
script go under out/web/.

The website uses the copies stored in media/.

Offset convention
-----------------
Offsets are printed as (x, y).
Positive x moves right and positive y moves down.
G and R are aligned to the blue channel.
